Резервная копия Pulsar в прежнем дизайне (до «Орбиты», версия 13.0).

**Скачать:** [Pulsar-classic.exe](https://github.com/Baton4Bl/pulsar-releases/raw/main/classic/Pulsar-classic.exe)

SHA-256: `F7DA0B2D35B6428885A21D1AB900AA5A1350B89DB82A32FB49926861A22DD09F`

Программа сама предложит обновиться до новой версии — от предложения можно отказаться.
Чтобы оно не появлялось, выключите «Настройки → Проверять обновления автоматически».
Классическая версия больше не получает исправлений.
